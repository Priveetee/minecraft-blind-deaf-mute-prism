# Minecraft Blind Deaf Mute

Instance client pour le serveur **Blind Deaf Mute** (`eltux.fr:31877`) - chacun perd un sens.

- Minecraft 1.21.4
- Fabric Loader 0.19.5
- Blind Deaf Mute 1.0.0 (le mod du mode de jeu)
- Simple Voice Chat 2.6.20 (obligatoire, force par le serveur)
- Sodium 0.6.13
- Fabric API 0.119.4
- Lithium, FerriteCore, Krypton
- Player Revive et Emotecraft (comme le pack officiel de l'auteur)

## Installation dans Prism Launcher

1. Ouvrir Prism Launcher
2. `Ajouter une instance` puis `Importer`
3. Coller l'URL du fichier `.mrpack` (release GitHub) ou selectionner le fichier telecharge
4. Lancer l'instance et se connecter a `eltux.fr:31877`

Le serveur exige le mod vocal : sans Simple Voice Chat, la connexion est refusee.
